# Module 01 — Inside AI Coding Assistants

**Purpose:** replace vague mental models of assistant “memory” with observable engineering mechanisms.

## Outcomes
By the end, learners can:
1. Distinguish model parameters, current prompt context, tool observations, repository instructions, and persistent external storage.
2. Describe the request/tool/action/observation cycle without assuming the LLM independently executes shell commands.
3. Propose controlled experiments to test whether repository knowledge persists across sessions.
4. Capture a baseline of quality, latency, intervention and cost signals.
