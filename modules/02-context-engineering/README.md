# Module 02 — Context Engineering

**Purpose:** design the information environment around an AI coding task so the assistant can find what matters, follow project conventions, and show evidence for its work.

**Status:** draft v0.1. Vendor-specific instruction discovery and precedence change over time; verify the references in the lesson before teaching.

## Outcomes

Learners can:

1. Map the information sources that shape a coding task and distinguish durable project knowledge from task-specific context.
2. Organize repository guidance by scope, ownership, freshness, and expected reuse.
3. Write concise, testable repository instructions with explicit source-of-truth links and conflict handling.
4. Evaluate whether instructions improve task quality across repeated, held-out tasks.
5. Identify stale, duplicated, contradictory, sensitive, or over-broad context before it affects a change.

## Suggested sequence

- Lesson: [Build a context architecture](lessons/01-build-context-architecture.md)
- Lab: [Design and test repository instructions](labs/01-repository-instruction-system.md)
- Assessment: [Module rubric](assessments/01-rubric.md)
- Instructor: [Teaching guide](instructor/01-teaching-guide.md)

## Deliverable

A context map, proposed instruction-file layout, a small instruction set, and a repeatable evaluation report showing where the guidance helped, failed, or was not applicable.
