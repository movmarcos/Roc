# Commercial release checklist

- [ ] Technical review by experienced engineer
- [ ] Vendor commands/features verified against current docs
- [ ] Labs tested from a fresh environment
- [ ] Student and instructor materials separated
- [ ] Accessibility and readability review
- [ ] License and copyright review, including diagrams/assets/screenshots
- [ ] Security and privacy review
- [ ] At least one pilot cohort and incorporated feedback
- [ ] Pricing and target audience validated with evidence
- [ ] Release notes, support policy and update cadence established
