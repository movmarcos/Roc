# AI Engineering Mastery — Beyond Prompting

A practical, vendor-neutral course for building reliable AI-assisted software engineering workflows.

## Course status

This repository contains the draft v0.1 starter set. Module 1 includes two lesson drafts, two hands-on labs, two instructor guide variants, and an assessment rubric. These materials are early drafts and need technical, instructional, security, and IP review before publication.

## Start here

1. [Course roadmap](curriculum/ROADMAP.md)
2. [Module 1 overview](modules/01-inside-ai-coding-assistants/README.md)
3. Choose a [lesson](modules/01-inside-ai-coding-assistants/lessons/01-context-is-not-memory.md) and [lab](modules/01-inside-ai-coding-assistants/labs/01-project-context-audit.md)
4. Capture outcomes with the [lab results template](templates/lab-results.md)

## Repository map

- `curriculum/` — roadmap and curriculum-level decisions

- `templates/` — reusable lesson, lab, and results templates
- `governance/` — editorial and review standards
- `commercial/` — product strategy, brief, and release checklist drafts
