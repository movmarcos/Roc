# ROC — AI Engineering Mastery

ROC is the repository for **AI Engineering Mastery — Beyond Prompting**, a practical AI training course.

## Project status

The course structure, Module 1, practical lab, and instructor materials were developed in the associated ChatGPT Project. They have not yet been migrated here. The current repository documents the agreed structure and transfer steps while we retrieve those original materials.

## Repository map

- [Curriculum](curriculum/README.md) — proposed course structure and curriculum status
- [Project handover](PROJECT_HANDOVER.md) — decisions, current status, and migration steps
- `modules/` — course modules, lessons, labs, and assessments
- `instructor/` — instructor materials
- `commercial/` — product and commercial materials
- `examples/` — reusable examples

## Workflow

Use the ChatGPT Project for course architecture, drafting, and review. Keep approved material in this repository as the durable source of truth. Transfer the existing materials from their source files rather than recreating them from memory.
