# AI Engineering Mastery — Beyond Prompting

A practical, vendor-neutral course for building reliable AI-assisted software engineering workflows.

## Start with the ROC portal

Visit the [ROC training portal](https://movmarcos.github.io/Roc/) to follow the course sequence, see what is available, and track your progress in this browser.

## Course status

This repository contains draft v0.1 course materials. Module 1 has lessons, hands-on labs, instructor guides, and an assessment rubric. Module 2 is in development. Course materials need technical, instructional, security, and IP review before publication.
